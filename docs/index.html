Zero-Node Installation

Up and running in 30 seconds.

The compiled React UI ships bundled inside the Python package — no Node.js, no Python 3.7 legacy environment, and works natively on macOS, Linux, and Windows (Python 3.10+). 

# Install directly from GitHub (Python 3.10+)
pip install git+https://github.com/pritampanda15/PandaProtein.git

# Or install in an isolated environment with pipx or uv:
pipx install git+https://github.com/pritampanda15/PandaProtein.git
uv tool install git+https://github.com/pritampanda15/PandaProtein.git

# Launch the full 3D workbench (auto-picks an open port & opens browser)
pandaprotein

# Optional: open a specific PDB entry directly from the CLI
pandaprotein --pdb 6GGD
# On your remote cluster / compute node (token-protected + auto-exit after 15 min idle):
pandaprotein --host 127.0.0.1 --port 8000 --no-browser --token --idle-exit 15

# On your local machine, forward the port via SSH and open the printed ?t=<token> URL:
ssh -L 8000:127.0.0.1:8000 user@cluster.university.edu

# Behind an institutional reverse proxy (no path rewriting required):
pandaprotein --base-path /pandaprotein --no-browser
git clone https://github.com/pritampanda15/PandaProtein.git
cd PandaProtein

python3 -m venv .venv
.venv/bin/pip install -r requirements.txt

npm --prefix frontend install
npm --prefix frontend run build    # compiles React UI & syncs backend/static/

./start.sh --dev                   # FastAPI :8000 + Vite HMR :5173
CLI Flag / URL Parameter Description Example
--port / --host Custom bind host & port (auto-increments if busy) pandaprotein --port 8080
--token Enforces random access token (?t=… / header) for shared servers pandaprotein --token --no-browser
--base-path Serve cleanly under a reverse-proxy URL prefix pandaprotein --base-path /pandaprotein
--idle-exit MIN Auto-stop cleanly after N minutes with no open browser tab pandaprotein --idle-exit 10
--reuse Open a new tab on an already-running local PandaProtein server pandaprotein --reuse --pdb 4A1X
?pdb=&assembly=&tab= URL deep-link directly into an entry, Biomol assembly, and panel /?pdb=6GGD&assembly=2&tab=prep-tree
Worked Benchmark Cases

Real-world structural preparation workflows.

Launch PandaProtein locally and open any of these worked structures to test biological assemblies, ion typing, gap rebuilding, and ion-channel profiling.

Case 1 · SARS-CoV-2 Mpro (6LU7) — Dimer & Native Redock Prep

Loaded by default on launch. Open Prep Tree (ADapt) to switch between ASU and Biomol 1, inspect the N3 inhibitor's native binding-site grid box coordinates in Ligands & Metals, protonate via PROPKA 3.5.1 at pH 7.4, and export Vina 1.2 / PandaX .pdbqt + MD5 provenance_session.json.

URL: /?pdb=6LU7&tab=prep-tree

Case 2 · Metalloprotease (6GGD) — Biomol 2, Zinc Charges & AltLocs

Fetch 6GGD and select Biomol 2. Keep catalytic ZN 401 in the receptor with verified +2.0 CCD formal charge, assign EYB 402 as Ligand (1-click .pdbqt export), resolve alternate locations with occupancy radio pills, or mutate active-site residues in COOT Workbench.

URL: /?pdb=6GGD&assembly=2&tab=prep-tree

Case 3 · Missing Loops (4A1X) — REMARK 465 Markers & Refusal Gate

Fetch 4A1X to see internal gaps drawn as dashed orange lines with midpoint spheres and missing termini as amber markers in 3D. Click Rebuild Gap to run 3-seed FABRIK closure with strict C–N, CA–CA, ω, chirality, and clash checks — passing loops render in magenta while unclosable gaps are refused with diagnostics.

URL: /?pdb=4A1X&tab=prep-tree

Case 4 · KcsA Ion Channel (1K4C) — HOLE Pore Radius & 3D Bilayer

Fetch 1K4C, open Compare & Nets to align the transmembrane belt onto +Z and render the realistic 3D phospholipid bilayer, then run HOLE inside Tunnels & Pores to profile the TVGYG selectivity filter radius R(s) and pore conductance (pS).

URL: /?pdb=1K4C&tab=tunnels
